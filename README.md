# obsidian-tools

Cross-platform Python tools for managing, backing up, validating, and analyzing Obsidian vaults.

## Features

- Obsidian vault management.
- Backup and integrity checks.
- Metadata validation and analysis.
- Windows and Linux interoperability.

## Requirements

- Python 3.10 or later.

## Usage

Each tool provides its own command-line help:

```bash
python <tool-name>.py --help
```
